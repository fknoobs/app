Suggest adding a head-to-head (H2H) feature so that players can view their win/loss record against any specific opponent. If storing full history in the database is too resource-intensive, perhaps begin by supporting H2H stats for just the last X games (the exact number per mode can be decided—possibly around 10). Since the data for these recent games is already accessible, this could be implemented without additional storage requirements.

# For tourneys

Establish a clear rule requiring all tournament participants to check the designated tournament Discord channel at least once per day for any important updates or announcements. When an official announcement is made, each participant must acknowledge they've read it by reacting to the message with a checkmark emoji. This ensures everyone stays informed and can respond promptly to schedule changes, rules updates, or other important information.
